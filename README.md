# 🛡 Warden

**Identity and access for AI agents.**
An open-source gateway that checks every tool call an AI agent makes against your firm's rules
(who it acts for, the engagement, ethical walls, roles) and records every decision.

## What's in this repository

| Folder | What it is |
|---|---|
| [`warden/`](warden/) | **Warden**: the gateway, its admin console, tests, docs and Azure deployment. Start here. |
| [`tickmark/`](tickmark/) | **Tickmark**: a demo AI agent and MCP tool server (invoice vouching) used to show Warden working end to end. |

Warden works with any MCP agent and any MCP tool server; Tickmark is just the example.
